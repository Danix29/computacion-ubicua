## About

**Ubiquitous Computing** (Computación Ubicua) · Universidad de Alcalá, Grado en Ingeniería Informática.

Pervasive, context-aware systems: devices that **sense, process and act** on the physical world. From sensors and microcontrollers to servers, IoT architectures, cloud, smart cities and Industry 4.0.

## Syllabus

| Block | Hours | Content |
|---|---|---|
| Ubiquitous computing | 4 h | Unit 1 · Introduction and related technologies |
| Intelligent systems | 16 h | Unit 2 · Sensors, actuators and microcontrollers |
| Servers | 8 h | Unit 3 · Introduction to server-side programming |
| IoT and cloud | 8 h | Unit 4 · Internet of Things, architectures, communication protocols, cloud computing |
| Smart cities and Industry 4.0 | 8 h | Unit 5 · Integrated services, frameworks |
| Project development | 16 h | Unit 6 · Proposals, validation and project presentation |

## Units covered so far

- Unit 1 · Introduction to ubiquitous computing
- Unit 2 · Sensors, actuators and microcontrollers (in progress)

## What I'm expected to be able to do

- Evaluate interface-design characteristics for computing systems
- Know the available development platforms and pick the right one for the problem
- Apply the foundations, paradigms and techniques of intelligent systems
- Choose development methodologies for smart-environment systems

## Practices

| # | Name | Goal | Status |
|---|---|---|---|
| PECL1 | **Design of a ubiquitous-computing system** | Design, as a team, a system for a real problem (smart campus, agriculture, industry, parking, energy, environment, accessibility): requirements, sensor/actuator architecture, communication protocols, information flow and a state-of-the-art review, written up as a technical report. The first practice is a design, not a build | 🟠 Assigned |
| PL2 / PL3 | **Implementation practices** | Follow-up practices, weighted 15 % and 30 % | ⚪ Upcoming |

## Assessment

| Instrument | Weight |
|---|---|
| Theory exams (PEI1 + PEI2) | 20 % + 20 % |
| Practices PL1 / PL2 / PL3 | 15 % / 15 % / 30 % |

Final route: final exam 40 % + practices 60 %.
